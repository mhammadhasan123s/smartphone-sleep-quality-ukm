## Stage 1 — Survey Design

The survey was designed using the **XLSForm standard**, which allows bilingual (English / Malay) forms to be deployed on [KoboToolbox](https://www.kobotoolbox.org/).

**File:** `survey/phone_sleep_survey_design_xlsform.xlsx`

The form contains three sheets:

| Sheet | Purpose |
|---|---|
| `survey` | Question definitions, types, labels, constraints, skip logic |
| `choices` | Answer option lists (gender, study level, app type, sleep quality, etc.) |
| `settings` | Form title, ID, version, default language |

**Key design decisions:**

- **Consent gate:** All questions are skipped if the respondent does not consent (`relevant = ${consent} = 'yes'`)
- **Validation constraints:** `age` is restricted to 18–60; `phone_hours` to 0–24; `sleep_hours` to 3–12
- **Bilingual labels:** Every question and choice has both an English and a Malay label
- **Grouped sections:** Demographics, Phone Use, and Sleep Quality are in separate `begin group / end group` blocks

**Survey link (KoboToolbox):** https://ee.kobotoolbox.org/x/7v2OW2mb

## Stage 3 — Data Cleaning (in R)

**Script:** `R/Phone_Use_vs_Sleep.R` — Section 2

The following cleaning steps are applied in order:

| Step | What was done |
|---|---|
| Select columns | Kept 8 survey columns; dropped 16 KoboToolbox metadata columns |
| Remove blank row | Dropped 1 fully-blank submission (row 13 in raw export) |
| Fix encoding | Corrected mojibake from KoboToolbox latin1 export: `"Bachelorâs Degree"` → `"Bachelor's Degree"`, `"16â\x80\x9330 minutes"` → `"16-30 minutes"` |
| Recode ordinals | `sleep_quality` → `sleep_quality_score` (1–4, higher = worse); `sleep_latency` → `sleep_latency_ord` (1–4) |
| Factor encoding | `gender`, `study_level`, `app_type`, `sleep_quality`, `sleep_latency` → ordered/unordered factors |
| Derived variable | `user_group`: Light (≤4 h) / Mid (4–10 h) / Heavy (>10 h) from `phone_hours` |
| Drop key NAs | Removed rows missing `phone_hours` or `sleep_quality_score` |
| Save output | `phone_sleep_clean.csv` written to working directory |

**Result:** 47 rows × 11 columns, zero missing values in key variables.

## Stage 4 — Analysis

**Script:** `R/Phone_Use_vs_Sleep.R` — Sections 3–5

### Variables

| Variable | Type | Description |
|---|---|---|
| `age` | numeric | Respondent age (years) |
| `gender` | factor | Male / Female |
| `study_level` | ordered factor | Diploma → Bachelor's → Master |
| `phone_hours` | numeric | Daily smartphone usage (hours) |
| `app_type` | factor | Most-used app category |
| `sleep_hours` | numeric | Nightly sleep duration (hours) |
| `sleep_latency` | ordered factor | Time to fall asleep (4 levels) |
| `sleep_quality` | ordered factor | Self-rated quality (Very good → Very bad) |
| `sleep_quality_score` | integer | 1 = Very good … 4 = Very bad |
| `sleep_latency_ord` | integer | 1 = <15 min … 4 = >60 min |
| `user_group` | ordered factor | Light / Mid / Heavy user |

### Descriptive Statistics

| | Phone Usage (h/day) | Sleep Quality Score |
|---|---|---|
| Mean | 7.81 | 2.04 |
| SD | 4.81 | 0.72 |
| Median | 6 | 2 |
| Min | 2 | 1 |
| Max | 21 | 4 |

### Hypothesis Testing

| Test | H₀ | H₁ | p-value | Decision |
|---|---|---|---|---|
| Phone usage | μ = 6 h/day | μ > 6 h/day | 0.0066 | Fail to reject H₀ |
| Sleep quality | μ = 2 | μ ≠ 2 | 0.6876 | Fail to reject H₀ |

### Correlation & Regression

- **Pearson r = 0.23** — weak positive, not statistically significant
- **Model:** `sleep_quality_score = 1.77 + 0.035 × phone_hours`
- **R² ≈ 5%** — phone hours explain very little variance in sleep quality

### Monte Carlo Simulation (1,000 resamples)

- Sampling distributions of mean, SD, median, and range are approximately normal
- Bootstrap correlation centres at r ≈ 0.2; 95% CI spans zero → weak, unreliable signal

## Conclusion

While heavy smartphone use is common among UKM students (mean ≈ 7.8 h/day), its impact on sleep quality appears **weak** in this sample. No statistically significant relationship was found between daily phone usage and sleep quality. The Monte Carlo simulation confirms the observed correlation (r ≈ 0.23) is consistent but unreliable. Future studies should use larger samples and objective sleep measurement tools.
